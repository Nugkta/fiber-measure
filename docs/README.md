Project documentation hub: the lab-notebook system (metalabbook index →
per-study labbooks → per-study reports), per-feature design docs, and archived
implementation plans. Protocol and templates live in the repo-root CLAUDE.md.

## Contents

- `metalabbook.md` — current — single index table of all studies (slug,
  status, dates, one-line summary), sorted by Last Updated descending.
- `labbooks/` — current — one dated-entry notebook file per study.
- `features/` — current — one design doc per substantial feature.
- `report/` — current — one intro/method/results/discussion report per
  study whose main experiment has run; currently `01_esf_edge_consistency.md`
  (+ its `01_esf_ab_summary.png` figure).
- `superpowers/plans/` — archive — committed implementation plans
  (repo convention); currently the 2026-07-31 tilt-corrected diameter plan.
